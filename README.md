# 🎓 College Chatbot using Streamlit

This is an AI-based chatbot built using Python, Streamlit, and Machine Learning (Logistic Regression).  
It helps students get answers to common college-related queries like admission, fees, courses, placement, etc.

---

## 🚀 Features

- 💬 Interactive chatbot interface
- 🎓 Answers college-related questions
- ⚡ Quick response using ML model
- 🖥️ Beautiful Streamlit UI
- 📚 Predefined dataset using intents.json

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- NumPy
- NLP (TF-IDF Vectorizer)
- Logistic Regression
